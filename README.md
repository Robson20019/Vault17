# Vault17

MVP do HackMeridian 2026: credito em stablecoin com estoque de terras raras como colateral (Stellar / Soroban, testnet).

> Todos os dados sao FICTICIOS / DE DEMONSTRACAO. O token representa um direito simulado, nao propriedade legal do material.

## Pre-requisitos
- Rust 1.95+ com target `wasm32v1-none`
- Stellar CLI 27
- Node 22
